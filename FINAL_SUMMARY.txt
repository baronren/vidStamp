KEY DESIGN DECISIONS
═══════════════════════════════════════════════════════════════════════════════

✅ CRITICAL: Complete Payload Per Frame
   Every frame embeds the full 48-bit payload, ensuring:
   - Any 5-minute segment (7,200 frames @ 24fps) has thousands of payloads
   - Maximum robustness against frame drops and temporal attacks
   - Simple implementation without complex state management

✅ CRITICAL: Real-Time Optimization Strategy
   Original: Diffusion-based (1000ms/frame) → Too slow
   Solution: Distilled single-pass encoder (10-30ms/frame)
   - Remove diffusion process completely
   - Train student network to mimic teacher (offline)
   - Single forward pass in production

✅ CRITICAL: DCI Timestamp Logic
   Standard Unix timestamp → NOT DCI compliant
   DCI timestamp: 15-minute intervals, yearly reset
   - Increment: Every 15 minutes
   - Range: 0-65535 (16 bits, ~683 days)
   - Reset: Annually at year boundary

✅ Ring Buffer for Temporal Consistency
   VidStamp requires multi-frame context for robustness
   - 8-frame sliding window (configurable)
   - Zero-copy GPU memory layout
   - Supports 3D convolution/attention mechanisms

✅ Production-Ready C++ Interface
   Media Blocks use C++, not Python
   - PIMPL pattern for binary compatibility
   - Comprehensive error handling
   - Performance monitoring built-in
